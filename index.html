Development Repo

Everything you need to manage bots

Powerful, intuitive, and designed for efficiency. Web AFK Client brings professional management tools to your fingertips.

Multi-Bot Management

Connect and manage unlimited bots simultaneously from a single unified interface.

Live Chat Console

Monitor server chat in real-time and send messages or commands directly to any bot.

Movement Controls

Direct control with WASD and Jump. Navigate your bots through the world effortlessly.

Anti-AFK

Built-in smart logic to prevent being kicked for inactivity on any Minecraft server.

Auto-Reconnect

Automatically restores connections if bots get disconnected from the server.

Proxy Support

Route bots through SOCKS/HTTP proxies for enhanced security and privacy.

Account Manager

Securely save and manage multiple bot credentials for quick deployment.

Configurable Settings

Toggle physics, sneaking, and set custom join messages for each bot.

Installation & Setup

1

Backend Setup

The bot manager handles Minecraft connections on port 25582.

Terminal

cd backend

npm install

# Start the bot manager

npm start

2

Frontend Setup

The web interface will be accessible at port 8080.

Terminal

cd ..

npm install

# Run development server

npm run dev
